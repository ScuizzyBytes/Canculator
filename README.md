# 🧮 Modern Calculator GUI (CustomTkinter)

Графический калькулятор с современным интерфейсом, написанный на **Python** с использованием библиотеки **CustomTkinter**.

Программа позволяет выполнять базовые арифметические операции через удобное графическое окно с большими интерактивными кнопками и экраном вывода.

---

## ✨ Особенности

* 🎨 **Современный стиль**: Построен на базе `CustomTkinter` со скругленными элементами и чистым контрастным экраном.
* ➕ **Базовые математические операции**: Поддержка сложения (`+`), вычитания (`-`), умножения (`*`) и деления (`/`).
* 🧹 **Удаление символов**: Возможность посимвольного удаления ввода кнопкой `#`.
* 🎯 **Умное форматирование**: Автоматическое преобразование дробных результатов с целым значением в целые числа (без лишнего `.0`).
* 🔒 **Зафиксированный размер**: Окно программы со стабильным разрешением (`700x800`) без возможности случайного искажения интерфейса при изменении размера.
